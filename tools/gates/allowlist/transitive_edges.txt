# A recorded edge is skipped only when its CHILD is absent from the resolved
# graph. A recorded PARENT that does not ship is a failure, because the gate
# compares the whole recorded parent set against the shipping one — so a line is
# added by the epic that lands its package, not before (D-21). E01's header
# claimed otherwise and was wrong about parents; the gate is what the claim was
# checked against, and the gate wins.

# SPEC.md §14 records only the first. Both entry points — SvgPicture.network and
# the vector_graphics loader — are grep-banned by catchlaw-offline-guarantee, so
# the second parent widens the recorded graph and not the guarantee (D-21).
