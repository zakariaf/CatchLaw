## Why it is built this way

**Five screens, not twenty-three.** `CONVENTIONS.md` §6 and `FLUTTER_GUIDE.md` §6.4 both cap the matrix
at 4–6 screens, and `golden-two-lanes.md` is blunt about why: a golden cannot *assert* anything, only
that a set of pixels equals a set of pixels somebody blessed. Layout is proven far more cheaply by
computed geometry — which is what T06 does over all 28 surfaces. Goldens earn their keep for the four
things geometry cannot see: script joining, mirroring, numeral glyphs and painter output. The five
chosen screens are the ones where all four occur:

| Surface | Why it is in the matrix |
|---|---|
| S1 Check (home) | The launch target. Zone chip, currency chip, recents strip and tally bar are four mirrored chrome elements in one frame |
| S2 Species detail / result | The mixed-script header (`هامور Hamour · Epinephelus coioides`), the framed verdict stamp, the citation footnote with its Western-digit dates, and the ochre stale bar |
| S3 Ruler | The only `CustomPainter` in the matrix, and the one deliberate LTR island. T04 asserts its geometry; this lane photographs its glyphs |
| S5 Species search | A list of rows with a numeral hint (`45 cm`) beside a joined Arabic name — where a numeral column loses its spine first |
| S13 Rule text reader | Long Arabic legal prose at `t.legal`: `height: 1.80`, the 65-character measure, and the §9.6 language-availability notice |

**Two themes, and they are paper and sunlight.** `three-themes-and-modes.md` records that paper and
night both use five greys and bind the same thirteen slots to different primitives, so an Arabic
shaping or line-height regression appears identically in both — night is a second photograph of the
same failure. Sunlight has **zero** greys and `surfaceSunk == surface`, so any block that separated
itself with a change of stock instead of a rule is broken in sunlight and only in sunlight. Twelve
images per screen is the smallest matrix that covers both the type axis and the separation axis.
Night's neutral bindings are covered by E07's token tests and E19's pure-Dart contrast sweep, neither
of which needs a picture.

**Rejected: `alchemist`.** It is alive and it ships `loadAppFonts`, but `FLUTTER_GUIDE.md` §6.3 and
`golden-two-lanes.md` agree that its CI mode replaces glyphs with coloured blocks. A blocked-out
Arabic golden proves nothing about the one thing this matrix exists for. Built-in `matchesGoldenFile`
plus this harness, per §6.3's verdict for 2026.

**Rejected: `golden_toolkit`.** Discontinued, last published 2023-02-21, SDK constraint `<3.0.0`. It
cannot resolve on Dart 3, let alone the `^3.12.0` D-5 pins.

**Rejected: a second Ahem geometry lane.** `golden-two-lanes.md` describes two lanes, and for a
general app that is right. Here the geometry half of the job belongs to T06 and to E19's computed
`getRect` assertions, which fail with a sentence naming the cell that moved rather than with a diff
image. Adding an Ahem lane would double the file count to buy a weaker version of coverage that
already exists.

**One host, and it is Linux.** `FLUTTER_GUIDE.md` §6.4 point 2: font rasterisation, subpixel
positioning and antialiasing differ across hosts and engine revisions. The lane is
`@Tags(['golden'])`, `skip:`-ped unless `Platform.isLinux`, excluded from the default `flutter test`
run, and blessed only in a Linux container. CI never blesses — `golden-two-lanes.md` calls a blessing
step "a ratchet that approves whatever shipped", and a step in `validate.yml` greps the workflow
directory to make that structural rather than remembered.

**The coverage probe comes before the first blessing.** `flutter test` runs against a test font whose
every glyph is an identical em square, and an unloaded face renders notdef boxes. Either way six
locales produce six clean, stable, mutually-consistent images of nothing, and the matrix is worse than
absent because it looks green. E06/T08 put `loadAppFonts()` in `app/test/flutter_test_config.dart`;
this task refuses to trust it. `هامور` is five code points, so under Ahem it lays out at exactly
5 × fontSize; a joined Naskh run of the same five letters is materially narrower. The probe asserts
that inequality and the whole lane is `skip:`-ped behind it.

**Determinism comes from a frozen clock and fixture rows, not from the seeded database.** The clock is
pinned to `2026-03-12` so the Sha'ri closed-season line reads "day 12 of 61" (1 March – 30 April) in
every image, and the S2 pack is deliberately expired so the ochre `StaleRuleBar` is in all twelve S2
frames — invariant 5, photographed. Reading real content from `reference.db` here would make every
image churn on every content commit; T05 is the task that runs against the seeded database, and it
asserts rows rather than pixels.

## Tests first

Write the harness, then all 63 tests, then run. **They must fail.** The three guards fail on behaviour;
the 60 goldens fail with `Could not be compared against non-existent file`, which is the correct first
failure for a golden. If any golden passes before a file exists, something wrote one — find it before
going further.

`<locale>` is `ar`, `en`, `es`, `gl`, `ca`, `pt_BR`; `<theme>` is `paper` or `sunlight`. Every
generated description interpolates both, per `CONVENTIONS.md` §5, so `--plain-name ' ar - '` selects
the ten Arabic frames and nothing else.

```dart
// app/test/ui/golden/golden.dart   — helper, NOT a *_test.dart file
import 'dart:io' show Platform;

import 'package:catchlaw/theme/lonja_theme.dart';
import 'package:flutter/widgets.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:intl/number_symbols_data.dart' show numberFormatSymbols;

/// The six shipped locales, in the order `DECISIONS.md` D-3 lists them.
const kGoldenLocales = <Locale>[
  Locale('ar'),
  Locale('en'),
  Locale('es'),
  Locale('gl'),
  Locale('ca'),
  Locale('pt', 'BR'),
];

/// `pt_BR` rather than `pt-BR`: the tag is a filename fragment, not a BCP-47 tag.
String localeTag(Locale l) =>
    l.countryCode == null ? l.languageCode : '${l.languageCode}_${l.countryCode}';

/// paper and sunlight only — night shares paper's five greys. See "Why it is built this way".
enum GoldenTheme { paper, sunlight }

/// One shot in the matrix: a stable id, and the state it is pumped with.
final class GoldenSurface {
  const GoldenSurface({required this.id, required this.title, required this.build});
  final String id;                                     // 's02_result'
  final String title;                                  // 'S02 result'
  final Widget Function() build;
}

/// 360x800 at DPR 3.0 — the tightest shipped layout, per the widget-golden harness presets.
void useGoldenDevice(WidgetTester tester) {
  tester.view.devicePixelRatio = 3.0;
  tester.view.physicalSize = const Size(360 * 3.0, 800 * 3.0); // physical px: logical x DPR
  addTearDown(tester.view.reset);
}

/// Snapshot and restore the process-wide symbol table around every test in the lane.
/// T03 replaces this with the shared guard in app/testing/l10n/numeral_symbols.dart —
/// it does not exist yet, and two copies of a process-wide reset is exactly the drift
/// CONVENTIONS.md §4 warns about, so it lives here for one task only.
void guardNumberFormatSymbols() {
  late Object arabicSymbols;                 // NOT `late final` — it is set per test
  setUp(() => arabicSymbols = numberFormatSymbols['ar']!);
  tearDown(() {
    numberFormatSymbols['ar'] = arabicSymbols as dynamic;
    expect((numberFormatSymbols['ar']! as dynamic).ZERO_DIGIT, '0',
        reason: 'a test in this isolate swapped numberFormatSymbols and did not restore it');
  });
}

/// The lane runs on one host. Everything else is churn (FLUTTER_GUIDE §6.4 point 2).
final String? kNonLinuxSkip =
    Platform.isLinux ? null : 'goldens are blessed on ubuntu-latest only';
```

```dart
// app/test/ui/golden/screen_matrix_golden_test.dart
@Tags(['golden'])
library;

import 'package:flutter/material.dart';
import 'package:flutter_localizations/flutter_localizations.dart';
import 'package:flutter_test/flutter_test.dart';

import 'golden.dart';

void main() {
  guardNumberFormatSymbols();

  test('GoldenMatrix supports all six locales through GlobalMaterialLocalizations', () {
    final supported = GlobalMaterialLocalizations.delegate.supportedLocales.toSet();
    for (final locale in kGoldenLocales) {
      expect(supported.any((s) => s.languageCode == locale.languageCode), isTrue,
          reason: 'flutter_localizations ships no delegate for ${locale.languageCode} — '
              'vendor one before blessing this lane (epic Risk 5)');
    }
  });

  testWidgets('GoldenMatrix lays out هامور narrower than five em squares', (tester) async {
    // Ahem lays every glyph out as one em square, so five code points measure exactly 5 x 20.
    // A joined Naskh run of the same five letters is materially narrower. If this passes at
    // 100.0 the bundled Arabic face is not loaded and every ar image below is a picture of
    // nothing (FLUTTER_GUIDE.md §6.4, point 1).
    final painter = TextPainter(
      text: const TextSpan(
        text: 'هامور',
        // The Naskh stack the ar ramp resolves to — lonja-typography rule 9.
        style: TextStyle(fontSize: 20, fontFamilyFallback: LonjaFaces.arabic),
      ),
      textDirection: TextDirection.rtl,
    )..layout();
    expect(painter.width, greaterThan(0));
    expect(painter.width, lessThan(100.0),
        reason: 'هامور measured ${painter.width} at 20px — the Arabic face is not loaded');
  });

  for (final surface in kGoldenSurfaces) {          // 5 entries
    for (final locale in kGoldenLocales) {          // 6 locales
      for (final theme in GoldenTheme.values) {     // 2 themes
        // Loop AROUND testWidgets, never inside it.
        testWidgets(
          '${locale.languageCode} - ${surface.title} matches its golden '
          'in the ${theme.name} theme',
          (tester) async {
            useGoldenDevice(tester);
            await tester.pumpGoldenSurface(surface, locale: locale, theme: theme);
            await expectLater(
              find.byKey(ValueKey(surface.id)),
              matchesGoldenFile('goldens/${surface.id}_${localeTag(locale)}_${theme.name}.png'),
            );
          },
          skip: kNonLinuxSkip,
        );
      }
    }
  }
}
```

**Run:** `cd app && flutter test --tags golden test/ui/golden/` → on Linux, 60 missing-file failures
plus whatever the two probes report. On macOS, 60 skips and two probe results — which is why the
blessing happens in a container and not on the developer's machine.

## Implementation outline

The tests are red. Now, in order:

1. Write `golden.dart`: `kGoldenLocales`, `localeTag`, `GoldenTheme`, `GoldenSurface`,
   `useGoldenDevice`, `guardNumberFormatSymbols`, `kNonLinuxSkip`.
2. Add the `pumpGoldenSurface` extension on `WidgetTester`: `ProviderScope` with the fixture
   overrides, a `Clock.fixed(DateTime.utc(2026, 3, 12))` on `clockProvider`, `MaterialApp` carrying
   `locale`, the four localisation delegates, and `LonjaTheme.paper()` or `.sunlight()`. Layer
   `MediaQuery` above `MaterialApp` from `MediaQuery.of(context).copyWith(...)` — never a bare
   `MediaQueryData()`, which zeroes the size the device pin just set.
3. Populate `kGoldenSurfaces` with the five entries, each wrapping its screen in a
   `RepaintBoundary`-rooted widget carrying `ValueKey(surface.id)` so the golden captures the surface
   and not the whole `View`.
4. Fixture state, from `app/testing/models/`: a 38 cm Hamour against a 45 cm total-length minimum for
   S2 with an **expired** pack; a calibration of 6.299 px/mm with 380 mm committed for S3; the query
   `ham` with three rows for S5; one article of legal text plus the §9.6 notice for S13.
5. Run the two probes. **Do not proceed until both are green** — the coverage probe is the gate on
   everything below.
6. In a Linux container on the D-5 Flutter version, run
   `flutter test --tags golden --update-goldens test/ui/golden/` **once**. Open all 60 files. Confirm
   the six `ar` frames differ from the six `en` frames in shaping and not merely in string content;
   confirm every sunlight frame has one chromatic element and no grey; confirm the S2 frames all carry
   the ochre bar.
7. Commit the 60 files.
8. Add the `goldens` job to `.github/workflows/validate.yml`, reusing the Flutter setup step the
   existing analyze/test job already uses (E01), running `flutter test --tags golden` in `app/`, and
   preceded by:

   ```yaml
   - name: CI must never bless a golden
     run: |
       if grep -rn -- '--update-goldens' .github/workflows; then
         echo "::error::a blessing step turns the golden lane into a ratchet"; exit 1
       fi
   ```

9. Change the default test command to `flutter test --exclude-tags golden` so the developer loop does
   not pay for this lane.
10. Re-run the whole suite. Every earlier test still green.
